# @chutelang/formatter

Code formatter for the [Chute](https://chutelang.dev) programming language.

Part of the [`@chutelang/cli`](https://www.npmjs.com/package/@chutelang/cli) toolchain. Run `chute fmt` to format your Chute source files.
