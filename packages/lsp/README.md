# @chutelang/lsp

Language server for [Chute](https://chutelang.dev) with autocomplete, reference information, go-to-definition, and diagnostics.

Part of the [`@chutelang/cli`](https://www.npmjs.com/package/@chutelang/cli) toolchain. Run `chute lsp` to start the server.
